Work hours

Work hours is a small private tool for one household. A person enters the start time, end time and a short description of their work each day, and the tool builds a monthly working-hours report with daily, weekly and monthly totals.

The app runs on a private home server and is not available to the public. This page exists only to describe the app for Google sign-in.

Google Drive

When the user clicks "Open as Google Doc", the app saves the finished report as a new Google Doc in the user's own Google Drive. It can only see and change the files it creates itself, and never the rest of the Drive.
