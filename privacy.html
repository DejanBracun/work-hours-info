Privacy policy

Last updated: 30 September 2026. This policy applies to the private "Work hours" app (home page).

What the app stores

The app stores the working hours and descriptions that the user types in. They are kept in a database on a private home server and are not sent anywhere else.

What the app does with Google data

The app asks for one Google permission: https://www.googleapis.com/auth/drive.file. It is used only to create a new Google Doc containing the user's monthly report when the user clicks "Open as Google Doc".

  • The app can see and change only the files it created itself. It cannot read any other file in the user's Google Drive.
  • The only Google data the app keeps is a sign-in token, stored on the private home server. It is used to create those documents and nothing else.
  • Google user data is not shared with, sold to or disclosed to anyone, and is not used for advertising or to train any model.

Deleting your data

The user can revoke the app's access at any time at myaccount.google.com/permissions. Documents the app created stay in the user's Drive until the user deletes them. Data held by the app itself is deleted on request by the server's owner.

Changes

If this policy changes, the new version is published on this page with a new date.
